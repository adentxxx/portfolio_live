PEYRO – Transaction History

An international service for traffic arbitrage and paying for foreign goods and services.

#Fintech#B2C#Web & Mobile

Task

Make the transaction history easier and faster to work with.

Context

Transaction History is where users keep track of operations on their cards and accounts. The section had to be rebuilt: the filters and the list of operations were hard to read.

Problems found

A heavy, monotonous list

• No grouping by date; transactions of different types blend into one feed. • An operation doesn’t show which card it went through.

No single structure for the filter

Search, account selection, and team selection sit apart from the transaction type tabs and the “Generate statement” select.

Overloaded CTA

The accent “Generate statement” button distracted from the main task.

An extra step to search

Search is hidden behind a button: entering a query takes two clicks.

Inefficient filtering

Three selects made users open “Account”, “Card”, and “Team” one after another.

Design decisions

Transaction list

• Transactions are grouped by date, and each day has a heading. • Rows alternate their background, so the list is easier to scan. • Each operation has a type icon (top-up, decline, hold), plus the card number and name.

Filters and the statement button

The filters are gathered in one block and split by a divider. • Top: the period in a calendar and the transaction type in tabs. “Generate statement” was renamed “Download statement” and became an outline button, with no accent fill. • Bottom: a single “Account / Team / Card” select and the search field.

Built-in search

The search field is always on screen, so a query needs no extra click.

Combined select

Three filters are merged into one component: • Accounts • Teams • Cards If there are many cards or teams, a nested group can be collapsed so the list doesn’t swell.

Result

• Fewer extra steps in the filter. • Transactions are grouped by date and show more data. • One select for accounts, teams, and cards cut the time and the number of clicks.
